MEMBUAT AKUN GITHUB:
1. Buka https://github.com/signup
2. Daftar dengan email kantor atau email yang Anda kelola, buat kata sandi yang kuat, lalu selesaikan verifikasi.
3. Setelah masuk, buka https://github.com/new
4. Nama repository: kua-ngronggot.github.io
5. Pilih Public, lalu Create repository.
6. Di halaman repository, pilih Add file > Upload files.
7. Ekstrak ZIP ini di komputer, lalu unggah semua file di dalam folder (bukan file ZIP-nya).
8. Klik Commit changes.
9. Buka Settings > Pages.
10. Pada Build and deployment, pilih Deploy from a branch; branch main dan folder /(root), lalu Save.
11. Tunggu beberapa menit. Alamat yang direncanakan: https://kua-ngronggot.github.io

Catatan: GitHub dapat meminta verifikasi email. Jangan bagikan kata sandi atau kode verifikasi kepada siapa pun.
